# New client checklist

- [ ] Get: shop name, category, area, address, phone/WhatsApp, hours, Google Maps link
- [ ] Get: 3-6 photos (shop front, products, team), logo if they have one
- [ ] Copy the `template` folder, rename it to the client name
- [ ] Replace every {{TOKEN}} at the top of index.html (Find & Replace)
- [ ] Set data-theme: shop | service | clinic
- [ ] Add photos to images/ (jpg/webp, under 300 KB each)
- [ ] Test on your phone: images load, Call and WhatsApp buttons work
- [ ] Upload to GitHub, enable Pages, send the link
- [ ] Set up their Google Business Profile with the website link
- [ ] Collect the second 50% payment, offer the Care plan (Rs 500/month)
